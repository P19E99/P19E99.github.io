## 868. 二进制间距

考虑到只看相邻的 $1$ ，可以把 $n$ 的二进制从低位到高位遍历，记一下 $1$ 的位置，遍历过的位直接扔了就行，等遍历到下一个 $1$ 的时候减一下上一个 $1$ 的位置就中。

代码：

```cpp
class Solution {
public:
    int binaryGap(int n) {
        int pos = -1, mx = 0, cnt = 0;
        while(n) {
            if (n & 1) {
                if (pos != -1) mx = max(cnt - pos, mx);
                pos = cnt;
            } 
            cnt++;
            n >>= 1;
        }
        return mx;
    }
};
```
